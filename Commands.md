# Commands                                    # What does it do?
```diff
+ git init                                    Start Git in this folder
+ git status                                  Check staged and untracked files
+ git add George.py                           Stage a specific file
+ git add .                                   Stage all changes in project

! git commit -m "your message"                Save staged snapshot
! git log --oneline                           View single-line commit history
! git push origin main                        Upload commits to GitHub
! git push origin main --force                Force overwrite remote repository
! git pull origin main                        Download latest files to VS Code

- git restore <filename>                      Restore a deleted file
- git reset --hard <commit-hash>              Roll back project history

+ pwd                                         Where am I?
+ ls                                          List the files here.
+ cd folder                                   Go into a folder.
+ cd ..                                       Go one folder up
+ clear                                       Clean the screen 
```
